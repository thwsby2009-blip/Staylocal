## 2. Staylocal 產品實測（自己測的，條件見各條）

| 實測 | 日期 | 條件 | 結果 | 用在哪個結論 |
|---|---|---|---|---|
| **瑞典文逐句相似度** | 2026-10 | 丹麥/瑞典影片，SenseVoice 對照 | 逐句相似度 0.64→0.78→0.80（v28→v33）；完全相符約半數 | 「good/edge 級的語音品質只是可用，不是高品質」的證據；README 已知限制節 |
| **AGC 增益對 CER 的影響** | 2026-11 | 同一段韓文三段，AGC 上限 60→150 | CER 0.18–0.39 → **0.092–0.096**（幾乎不動） | 「收音強度決定品質」的定量證據；AGC 上限 150 是實測值 |
| **SenseVoice 25 秒切段 vs 整段** | 2026-11-01 | 與 VoiceNotes 同設定重跑聯集實驗 | 25s 切段缺漏 4.2%、無整句級漏失；整段不切掉 43.7% | 「切長度是漏字主因」，證實 25 秒段設定 |
| **丹麥文模型硬轉瑞典文** | 2026-10 | 強制語言不匹配 | 「腔調像、字不對」 | 「來源語言必須選對」的實測依據 |
| **ML Kit 英文中繼走鐘** | 2026-10 | 韓→中 vs 韓→英→中手動拼接 | 兩者一字不差（證實 ML Kit 內部就是英文中繼）；中繼英文本身常走鐘 | 「鏈上最可信的是原文與中繼英文」 |

## 4. 如何重現/檢視

```bash
# 1. 對照分級：src/languages.ts 的 tier 標註 ↔ 本表第 1 節的 WER
grep -A 40 "tier 說明" src/languages.ts

# 2. 自己跑 Whisper 論文的數字：下載 FLEURS + whisper small 推論
#    https://github.com/openai/whisper + https://huggingface.co/datasets/google/fleurs

# 3. 檢視 Staylocal 實測的原始記錄：
#    - 瑞典文相似度實驗：repo 主人會話檔（2026-10）
#    - AGC CER 實驗：README 已知限制節引用的韓文三段
#    - 切段聯集實驗：姊妹專案 VoiceNotes repo 的 VOICENOTES_DEV_LOG.md（2026-11-01 節 6f）
```

**閱讀提醒**：第 1 節是「理想條件」（朗讀、乾淨錄音），實機會更差；第 2 節是「本產品條件下的實測」，樣本少但真實。兩者方向一致（品質排序），絕對值不能互換。
